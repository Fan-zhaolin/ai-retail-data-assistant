# PRD：AI 零售数据问答助手
## 背景
产品和运营人员经常需要查询零售销售数据，例如品类销售额、渠道表现、地区差异、用户分层贡献等，但不一定会写 SQL。
## 目标用户
需要快速查询销售数据的产品、运营、业务分析人员。
## 核心流程
用户输入业务问题 -> 大模型生成 SQL -> SQL 安全校验 -> 查询 SQLite -> 展示表格/图表 -> 生成业务解释。
## 核心功能
1. 自然语言输入业务问题
2. 自动生成 SQLite SQL
3. 展示 SQL、查询结果和图表
4. 生成简短业务解释
5. 拦截危险 SQL
6. 自动运行评测并生成 results.csv
7. 自动沉淀 Bad Case，人工补充归因和优化方案
## 非目标
第一版不做登录权限、不连接生产数据库、不做复杂 BI 仪表盘、不做实时数据更新。
## 验收标准
- Demo 可本地启动
- 支持 40 条以上评测问题
- SQL 执行成功率达到（待填写）
- 答案正确率达到（待填写）
- 危险 SQL 拦截率 100%
